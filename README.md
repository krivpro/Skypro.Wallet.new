# Skypro Wallet

Веб-приложение для учёта личных расходов. Позволяет регистрироваться, добавлять и удалять транзакции, а также анализировать траты по категориям за выбранный день.

## Установка и запуск

Требования: Node.js 18+ и npm.

```bash
# Клонировать репозиторий
git clone <url-репозитория>
cd Skypro.Wallet.new

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev

# Собрать production-версию
npm run build

# Предпросмотр production-сборки
npm run preview
```

После запуска `npm run dev` приложение откроется по адресу `http://localhost:5173`.

## Ключевые функции

- **Авторизация** — регистрация и вход с сохранением JWT-токена в `localStorage`
- **Учёт расходов** — таблица транзакций, добавление и удаление записей
- **Анализ расходов** — календарь выбора дня и диаграмма трат по категориям
- **Защита маршрутов** — доступ к страницам расходов только для авторизованных пользователей

## Технологии

| Технология | Назначение |
|------------|------------|
| React 19 | UI-компоненты |
| TypeScript | Типизация |
| Vite | Сборка и dev-сервер |
| React Router 7 | Маршрутизация |
| Fetch API | HTTP-запросы к бэкенду |

Бэкенд: [wedev-api.sky.pro](https://wedev-api.sky.pro/api).

## Структура проекта

```
src/
├── app/          — маршруты и guard-компоненты
├── pages/        — страницы приложения
├── features/     — доменная логика (расходы, аналитика)
├── layout/       — общая оболочка и шапка
└── shared/       — API-клиент, авторизация, валидация, UI-компоненты
```
